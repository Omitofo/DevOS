# Canonical Pipeline

```
Idea
  → Project Intake
  → Planner          → Project Brief
  → Analyst          → Requirements
  → Architect        → Architecture Blueprint
  → UX               → User Journey
  → UI               → Visual Blueprint
  → Tech Lead        → Implementation Plan
  → Security & Quality Auditor → Master Design Plan
```

## Stage Order (Mandatory)

1. Intake (human)
2. Planner
3. Analyst
4. Architect
5. UX
6. UI
7. Tech Lead
8. Security & Quality Auditor

No stage may be skipped.  
No implementation code may be produced before the Master Design Plan is approved.
