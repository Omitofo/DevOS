# Artifact Lifecycle

1. **Intake** — Raw idea + constraints (human-provided).  
2. **Project Brief** — Structured, scoped problem statement.  
3. **Requirements** — Traceable functional & non-functional requirements.  
4. **Architecture Blueprint** — System design with justifications.  
5. **User Journey** — Experience model.  
6. **Visual Blueprint** — UI/UX specification.  
7. **Implementation Plan** — Engineering work breakdown.  
8. **Audit Report** — Quality-gate results + residual risks.  
9. **Master Design Plan** — The single, approved, implementation-ready package.

## Required Content of Every Artifact

- Traceability links to upstream artifacts  
- Explicit assumptions (if any)  
- Open questions (if any)  
- Version / status header  

## Versioning & Retirement

Artifacts are versioned via Git.  
When a later stage supersedes an earlier artifact, the earlier artifact remains for audit trail; it is never silently deleted.
